# Code of conduct

cpu3d wants to be a friendly project for people of every background and experience level.

- Be kind and assume good intent. Critique code and ideas, not people.
- No harassment, insults, or discriminatory language, in any channel of the project.
- Help newcomers: there are no stupid questions about rasterizers.

Maintainers may remove comments, commits or contributions that break these rules and may block repeat offenders. Report problems privately to the maintainers through GitHub.
